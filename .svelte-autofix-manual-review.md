## Risk

Applying the autofixer’s suggestions here would be unsafe because:

- **Form fields** rely on writable state for `bind:value`; `$derived` values are read-only.
- **Drag-and-drop and crop editors** need mutable state for user interactions.
- **Theme/transition hydration** must run once on the client; it cannot be expressed as a pure derivation.
- **DOM side effects** (body overflow, inert, focus, history API) require imperative code in `$effect`.

Only refactor these after a careful review to ensure behavior is preserved.
